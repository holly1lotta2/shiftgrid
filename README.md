# ShiftGrid

График смен для кафе, ресторанов и магазинов вместо Excel и чатов.
Управляющий расставляет смены в недельной сетке, сотрудник видит свой график
и может попросить коллегу о замене. Часы и переработка считаются сами.

Работает локально на вашем компьютере — интернет нужен только при первом запуске
(чтобы скачать Flask) и для стилей Bootstrap.

## Как запустить

**Windows:** дважды щёлкните `start.bat`.

При первом запуске он создаст папку `.venv` и установит зависимости (около минуты),
затем откроет приложение в браузере. В следующие разы запуск занимает пару секунд.
Окно консоли не закрывайте, пока работаете: закрыли окно — сервер остановился.

**macOS / Linux:** `./start.sh`

**Вручную:**

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Нужен Python 3.10 или новее. Если `start.bat` пишет «Python не найден», установите Python
с python.org и при установке отметьте **Add python.exe to PATH**.

Адрес печатается в консоли: обычно `http://127.0.0.1:5000`. Если порт 5000 занят
другой программой (например, VPN), ShiftGrid сам возьмёт следующий свободный — 5001, 5002…

## Ссылка для одногруппников

Дважды щёлкните **`start-public.bat`**. Сайт запустится как обычно, а в консоли появятся
**две ссылки** — обе уже скопированы в буфер обмена, просто вставьте их в чат:

```
https://какие-то-слова.trycloudflare.com    (Cloudflare)
https://1a2b3c4d5e.lhr.life                 (localhost.run)
```

По ним сайт откроется у любого человека, с компьютера или телефона. Если одна ссылка
не открывается (некоторые провайдеры, особенно мобильные, режут Cloudflare) — пусть пробуют другую.

- Ссылки работают, пока открыто окно консоли и компьютер не уснул.
- Если связь оборвётся, туннель переподключится сам, а в окне появится **НОВАЯ ССЫЛКА** —
  её нужно переслать заново (буфер обмена обновится сам).
- При каждом запуске ссылки новые.
- Ссылка Cloudflare начинает открываться через 10–20 секунд после запуска.
- Регистрация не нужна. Для Cloudflare при первом запуске скачивается программа `cloudflared`
  (около 60 МБ) с официального GitHub Cloudflare в папку `tools/`. Для localhost.run используется
  `ssh`, встроенный в Windows 10/11.
- Щелчок мышью в окне консоли больше не замораживает сервер (режим выделения отключён).
- Если в окне при открытии ссылки появляются строки `"GET /login HTTP/1.1" 200` — запрос дошёл.
  Если ничего не появляется — ссылку не пропускает сеть или браузер того, кто её открывает.
- Кнопки быстрого входа остаются, чтобы одногруппники могли зайти и посмотреть.
  Чтобы кто-то по ссылке не стёр всё одной кнопкой и не запер демо-аккаунты, в этом режиме
  отключены «Сбросить к демо», «Очистить данные» и смена паролей. Если что-то испортят — закройте окно,
  запустите обычный `start.bat` и сбросьте демо в профиле.

## Демо-доступ

На странице входа есть кнопки быстрого входа — нажмите на человека.

| Кто | Логин | Пароль |
|---|---|---|
| Анна Смирнова, управляющий | `manager` | `manager123` |
| Иван Петров, бариста | `ivan` | `123456` |
| Мария Иванова, кассир | `maria` | `123456` |
| Пётр Сидоров, официант | `peter` | `123456` |
| Ольга Ким, повар | `olga` | `123456` |

В демо уже есть смены с начала текущего месяца до конца следующей недели (включая ночные),
переработка у Марии и две замены на разных этапах.

Чтобы обновить демо под сегодняшние даты: **Профиль → Сбросить к демо**.
Чтобы вести свою команду: **Профиль → Начать с чистого листа** — останется только ваш аккаунт.

## Что умеет

**Управляющий**
- **Главная** — кто работает сегодня и кто сейчас на смене, замены на утверждение, переработки.
- **График → Неделя** — таблица «сотрудники × дни»: «+» в ячейке ставит смену, клик по смене открывает
  её редактирование. Внизу видно, сколько смен и часов на каждый день, справа — часы каждого сотрудника.
- **«Скопировать прошлую неделю»** — график переносится одной кнопкой, пересечения пропускаются.
- **График → Месяц** — календарь, фильтр по сотруднику.
- **Смена** — быстрые кнопки времени (09–17, 22–06 и т.д.), должность подставляется из карточки
  сотрудника, кнопка «Добавить и создать ещё».
- **Сотрудники** — добавить, изменить, сбросить пароль, удалить; часы за любой месяц,
  переработка красным, **выгрузка в Excel (CSV)**.
- **Замены** — утвердить или отклонить, архив.

**Сотрудник**
- **Главная** — следующая смена крупно, отработанные часы, норма месяца, просьбы о замене от коллег.
- **Мой график** — неделя списком и месяц календарём, только свои смены.
- **Коллеги** — телефоны и кнопка «Попросить замену».
- **Замены** — попросить коллегу, согласиться или отказаться, отменить свою просьбу.

## Дизайн и скорость

- Стиль «Framed sheet» по правилам [taste-skill](https://github.com/Leonxlnx/taste-skill) для экранов
  приложений: светлая рамка с меню, работа на белом листе, шрифт IBM Plex Sans, без теней и градиентов.
  Цвет — только на данных: у каждого сотрудника свой бледный тон, красным — переработка и «дыры».
- **Полоса покрытия по часам** — 24 столбика над каждым днём недели и на главной: сколько людей
  на смене в каждый час. Пустые часы внутри рабочего дня отмечены красным — дыры в графике видны сразу.
- Bootstrap, иконки и шрифт лежат в `app/static/vendor` — сайт не ходит на внешние CDN.
  Ответы сжимаются gzip, статика кэшируется в браузере на год (в адресе — версия файла).
  Страница графика со всеми файлами: ~90 КБ вместо ~480 КБ.

## Правила

- **Замена в два шага:** сотрудник просит коллегу → коллега соглашается → управляющий утверждает,
  и смена переходит коллеге. Перед каждым шагом проверяется, что смена ещё впереди,
  принадлежит тому, кто просит, и коллега в это время свободен.
- **Ночная смена** (галочка «через полночь»): 22:00–06:00 = 8 ч, часы идут в день начала.
  Без галочки окончание раньше начала не принимается. Смена — не длиннее 16 ч.
- Смены одного человека не могут пересекаться (с учётом ночных).
- Закончившиеся смены сами становятся «Отработана». Отменённые смены в часы не входят.
- **Норма** — 160 ч в месяц, всё сверх неё — переработка.

## Безопасность

- Пароли хранятся в виде хэша, минимум 6 символов; CSRF-токен в каждой форме.
- Доступ по ролям проверяется на сервере: сотрудник получает 403 на страницах управляющего и видит
  только свои смены — фильтр стоит прямо в SQL-запросе.
- Все SQL-запросы параметризованы.
- Сервер слушает только `127.0.0.1`. Снаружи сайт доступен только через `start-public.bat` —
  по ссылке туннеля, пока открыто окно.

## Где лежат данные

`instance/shiftgrid.db` — база SQLite, `instance/secret_key` — ключ сессий
(с ним вход не сбрасывается после перезапуска). Чтобы начать полностью заново, остановите сервер
и удалите папку `instance`.

## Структура

```
shiftgrid/
├── start.bat / start.sh     запуск в один клик
├── start-public.bat         запуск + ссылка из интернета для одногруппников
├── run.py                   выбор свободного порта, открытие браузера, флаг --public
├── public_link.py           туннели Cloudflare и localhost.run с автоперезапуском
├── app/
│   ├── __init__.py          create_app()
│   ├── constants.py         норма часов, статусы, подписи
│   ├── timeutils.py         время смен, ночные смены, даты по-русски
│   ├── db.py                схема SQLite, демо-данные, сброс
│   ├── security.py          вход, роли, CSRF
│   ├── filters.py           фильтры шаблонов, страницы ошибок
│   ├── logic/               смены, часы и отчёты, сотрудники, замены
│   ├── views/               страницы: auth, dashboard, schedule, shifts, staff, swaps, account
│   ├── templates/           Jinja2 + Bootstrap 5
│   └── static/              style.css, app.js
└── tests/                   pytest
```
